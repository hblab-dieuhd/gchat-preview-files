01 File types

Which attachments get a Preview button. Plain .txt is absent on purpose — Google Chat already previews it.

HTML
.html .htm .xhtml
Markdown
.md .markdown .mdown .mkd
JSON
.json
Mermaid
.mmd .mermaid — the whole file drawn as one diagram
PlantUML
.puml .plantuml .pu .iuml .wsd

Whether these two are actually drawn is section 04. With drawing off they still open, showing the file’s source — which for PlantUML means nothing is sent to a server.

02 Scripts in HTML previews

Previewed files always run cut off from your Google account and from the network. This only controls whether their scripts run at all.

Allow scripts as soon as a preview opens
Off by default. You can still switch scripts on per preview, from the button in the preview window.
With this on, a file that draws a fake login form can capture what you type into it. It still cannot send anything out, but leaving this off is the safer default.

03 Linked resources in HTML previews

A page that gets its styling from a CDN shows up as unformatted text, because a preview is not allowed to reach the network — that is what stops a file from sending anything out. Switch this on and the extension downloads what the file links to and builds it in beforehand, so the page looks right while still being unable to reach anything itself.

Off unless you switch it on. The hosts listed below are only suggestions until then — nothing is downloaded, and Chrome is not asked for anything. Turn it back off and the permissions are handed back.

Load linked stylesheets, fonts, images and scripts
Only from the hosts below, only over https, and never with your cookies. Scripts still do not run until you allow them for that preview.
A host on this list learns that you opened a file linking to it — your IP address and roughly when. Saving asks Chrome for permission to reach each one. Keep the list to CDNs you recognise; anything else in a file is still blocked.

04 Drawing diagrams

Applies to both fenced blocks inside a Markdown file and whole .mmd / .puml attachments. Switched off, the source is shown instead of a picture.

Draw Mermaid
Drawn on your machine. Nothing is sent anywhere.
Draw PlantUML
PlantUML has no browser renderer, so the diagram source is sent to the server below to be drawn.
Diagram source is sent to plantuml.com. If your diagrams describe internal systems, point this at a PlantUML server inside your own network — Chrome will ask permission to reach it.
