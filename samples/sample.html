HTML preview test fixture

Everything below is a check on the extension, not a real page.

1. Does the document render at all?

If you can read this with a border around it and the heading above in bold, the html kind is passing the file through untouched, which is the whole contract for this kind.

2. Are scripts off?

Expected on open: scripts are OFF — the line below must still read "script did not run".

script did not run

After clicking Enable scripts on the preview it must change to "script ran". Both states are correct; seeing "script ran" before clicking is the failure, and it means allowScriptsByDefault leaked or the frame was rebuilt with the wrong sandbox flags.

3. Can the page reach the network?

The image below points at a real external host. It must render as a broken image — img-src is data: blob: only, and that is what closes the image-beacon exfiltration channel.

4. Can a form submit anywhere?

A page like this is the reason scripts are off by default. With a static render there is no keystroke capture, and form-action 'none' stops the POST. Type anything and press the button — nothing must leave the frame.

5. Can it escape the frame?

With scripts enabled, none of these may work: reading window.parent, opening a popup, or navigating the top frame. The frame has no allow-same-origin, no allow-popups, and no top navigation.
